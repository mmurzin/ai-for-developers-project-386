Разработайте совместно с ИИ сервис для бронирования календаря

## Сценарии

### 1. Владелец: от создания типа встречи до записи в списке

1. Владелец открывает страницу управления и создаёт тип встречи — указывает название, описание и длительность (например, «Консультация», 30 минут).
2. Новый тип встречи появляется в публичном списке — гости могут записываться по нему.
3. Гость бронирует свободный слот по этому типу (сценарий 2) — встреча сохраняется в базе.
4. В списке предстоящих встреч владельца появляется запись: тип встречи, дата и время, имя и email гостя.

### 2. Гость: запись на звонок

1. Гость заходит на публичную страницу без регистрации и выбирает тип встречи.
2. Открывается календарь на ближайшие 14 дней. Гость выбирает день и видит свободные слоты — слот длится столько, сколько выбранный тип встречи.
3. Гость выбирает свободный слот, указывает имя и email и подтверждает запись.
4. Слот становится занятым: это же время больше нельзя забронировать, даже другим типом встречи. Встреча появляется в списке владельца.

## Установка

<!-- Опишите установку: клонирование, зависимости, переменные окружения -->

Инструменты управляются через [mise](https://mise.run), версии зафиксированы в `mise.toml` (go, node, pnpm, golangci-lint, oapi-codegen, go-arch-lint):

```bash
git clone https://github.com/mmurzin/ai-for-developers-project-386.git
cd ai-for-developers-project-386
curl -fsSL https://mise.run | sh  # если mise ещё не установлен
mise install                      # ставит все инструменты из mise.toml
```

## Использование

<!-- Добавьте примеры запуска и запись asciinema — именно это смотрит работодатель -->

```bash
mise run dev               # бэкенд + фронтенд разом (Ctrl+C — остановить оба)
mise run run               # только бэкенд: http://localhost:8080/health
mise run frontend-dev      # только фронтенд: http://localhost:5173 (прокси /api → :8080)

mise run lint             # линтеры: golangci-lint (Go) + eslint (фронтенд)
mise run test             # тесты Go (gotestsum): smoke-тест запуска приложения
mise run frontend-test    # тесты фронтенда (Vitest + React Testing Library)
mise run build            # сборка бэкенда и фронтенда
```
